# 形 · 流 / Manifold

可交互的二维边界演化实验：绘制闭合形状，叠加局部速度场，观察表面张力与 KL 形状先验如何共同影响边界。

## 本地运行

项目使用原生 HTML、CSS 与 JavaScript，无需安装第三方依赖或构建。需要 Python 3 启动静态服务器：

```sh
python3 -m http.server 8000 --directory dist
```

在现代浏览器打开 <http://localhost:8000>。请通过 HTTP 访问，以便加载 JavaScript 模块。

## 操作

- **画笔（B）**：拖动绘制闭合轮廓，松手后保存为 KL 参考形状。只接受互不相交、无孔的简单闭合轮廓。
- **箭头（V）**：拖动添加局部速度场；选中箭头后调整粗细（强度）和影响半径，拖动箭头可改变位置或方向。
- **垃圾桶**：清空场景，恢复默认圆盘、参数与分辨率。
- **暂停 / 继续（空格）**：控制演化；关闭“外力”可观察先验回复，开启“初始轮廓”可对比形变。
- **Delete / Backspace**：删除选中的速度场；**Esc**：取消当前操作。

### 三种分辨率

| 设置 | 范围 / 默认值 | 作用 |
| --- | --- | --- |
| 画笔 → 轮廓分辨率 | 60–480 点 / 120 点 | 控制之后新绘制轮廓的边界采样与平滑程度；已有手绘形状不变。 |
| 选中初始圆盘 → 左侧采样点数 | 60–480 点 / 120 点 | 松开滑杆时重新采样当前圆盘边界并保持面积；保留其他形状与速度场。 |
| 箭头 → 场箭头分辨率 | 12–60 格 / 24 格 | 按画布短边设置速度场显示采样密度；不改变解析速度场、速度强度或边界运动计算。 |

更高的边界分辨率可保留更细的轮廓细节，也会增加计算量。

## 数学模型与范围

- **初始圆盘**：使用曲率流平滑边界，每步另行校正面积。在固定面积下，表面张力驱动边界趋向圆盘；表面张力本身不保证面积不变。
- **手绘形状**：将对应边界点建模为同方差高斯分布，以初始点为固定参考，使用平均 KL：`Σᵢ ‖qᵢ − qᵢ⁰‖² / (2Nσ²)`。这是边界对应点高斯分布之间的 KL，不是二值区域之间的 KL；它是鼓励恢复初始形状和位置的软先验，并非形状不变的硬约束。
- **局部速度场**：多个高斯衰减方向场叠加，再平滑限速。边界直接计算解析场值，显示网格仅用于可视化。
- **拓扑与微分同胚**：`H₀` 描述连通性，界面以 `β₀` 记录连通区域个数。边界数值积分和离散相交检查不能证明全局微分同胚。本项目是教学可视化，没有实现神经网络训练或反向传播。

## 检查

需要 Node.js；无需 `npm install`：

```sh
npm test
```

检查覆盖桌面与竖屏尺寸下的交互回调、形变回复、三种分辨率及重置。采用模拟 DOM / Canvas，不是实际浏览器的视觉排版测试。

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `dist/index.html` | 页面结构与模型说明 |
| `dist/style.css` | 响应式样式 |
| `dist/app.js` | Canvas 渲染与交互 |
| `dist/physics.js` | 边界、先验、速度场与数值演化 |
| `tests/ui-check.mjs` | 无第三方依赖的交互检查 |

`dist/` 是直接运行的源码目录，随仓库提交。
